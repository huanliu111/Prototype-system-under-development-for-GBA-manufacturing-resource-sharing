如何阅读这些结果

配置效率衡量实际实现的社会剩余占理论最大剩余的比例。它越高，说明资源越接近“给到最需要、成本最低的企业”。

成交价散点说明连续双向拍卖的路径依赖：即使均衡区间相同，逐笔价格仍会因报价顺序和策略而变化。

Smith α衡量成交价偏离理论均衡价的程度，数值越小表示价格偏离越小；它与估值反馈迭代的固定点残差是不同指标。
