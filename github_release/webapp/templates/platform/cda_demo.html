HOW TO READ

如何理解这个对比方法

离散单位报价

每家企业在同一轮中可以提交多个单位的买卖报价，而不是连续机时模型中的边际信号。

逐轮撮合

价格优先、时间优先，成交价由当时对手方的可接受报价决定；图中逐笔价格会随路径变化。

效率与均衡

实现效率衡量实际社会剩余占理论最大剩余的比例；均衡区间来自排序后的供需阶梯。

和论文算法的关系

它是一个独立的离散单位比较情景，用于展示“共享如何发生”；不替代第六章连续机时迭代算法的同场景福利检验。
