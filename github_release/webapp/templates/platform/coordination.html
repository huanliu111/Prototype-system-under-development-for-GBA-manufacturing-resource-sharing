HOW IT RUNS

从本地估值到协调结果

  1. 清算

    协调器使用买卖信号，在最低需求与供给容量约束下求解分配。

  2. 反馈

    企业侧模拟代理根据分配量计算边际收益或成本，返回下一轮信号。

  3. 松弛更新

    按 ρ 更新信号，持续检查固定点残差。

  4. 结算检查

    达到容差后检查每条执行关系的买卖价差、平台收支与参与方收益。

默认模拟采用对数收益和二次成本。运行结果保留失败状态与未收敛轨迹，可导出用于分析。
